# Juan Coronel — Personal Academic & Professional Portfolio

Bilingual (English / Spanish) academic portfolio and engineering showcase built with React 19, Vite, and Tailwind CSS v4.

## 🚀 Live Demo & Deployment
- **Deployment:** Automatically deployed via GitHub Actions to GitHub Pages.
- **Workflow:** `.github/workflows/deploy.yml`

## 🛠️ Tech Stack
- **Framework:** React 19 (^19.0.0, StrictMode)
- **Bundler:** Vite 6 (^6.2.0)
- **Styling:** Tailwind CSS v4 with custom editorial academic theme (Light & Dark)
- **Icons:** Lucide React
- **Package Manager:** Bun

## 💻 Local Development

```bash
# Navigate to the frontend directory
cd app/frontend

# Install dependencies
bun install

# Start local development server
bun run dev

# Production build
bun run build
```
